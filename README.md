
# 🎭 Playwright Automation Practice

A hands-on repository for learning and practicing browser automation using **Playwright and JavaScript**.

## 🎯 Objectives

- Practice reliable locators and assertions.
- Automate UI interactions and end-to-end workflows.
- Validate forms, dropdowns, dialogs, and error messages.
- Capture screenshots and troubleshoot failed tests.
- Learn reporting, retries, and CI/CD integration.

## 🛠️ Tech Stack

- JavaScript
- Playwright
- Node.js and npm
- Git and GitHub Actions

## 📂 Repository Structure

- `.github/workflows/` — CI workflow configuration
- `screenshots/` — Screenshots captured during practice
- `tests/` — Playwright test specifications
- `playwright.config.js` — Playwright test configuration

## 🚀 Getting Started

Install dependencies:

```bash
npm install
```

Install the required browser:

```bash
npx playwright install
```

Run all tests:

```bash
npx playwright test
```

Run tests with the browser visible:

```bash
npx playwright test --headed
```

Generate and open the HTML report:

```bash
npx playwright show-report
```
